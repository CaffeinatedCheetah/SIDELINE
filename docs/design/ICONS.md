# Icons

## Source and style

Use Lucide icons through direct named imports. Default stroke is 2 px with round
caps/joins. Do not mix filled third-party icon styles except approved team/league
marks and the FanTakes logo.

Sizes: 16 px inline, 20 px default controls, 24 px primary navigation, 32–48 px
empty states. Icon buttons remain at least 44×44 px.

## Semantics

- Decorative icons use `aria-hidden="true"` and cannot be the only label.
- Standalone icon buttons require an accessible name and tooltip on hover/focus.
- External links include an external-link icon plus screen-reader text.
- Live uses a dot plus “Live”; success/error/warning use icon plus text.
- Team logos have empty alt text when adjacent team name exists; otherwise alt
  is the team name.

## Approved mapping

- Home: House; games: Trophy; debates: MessagesSquare; communities: Users;
  search: Search; notifications: Bell; profile: UserRound; settings: Settings;
  create: Plus; reactions: Flame; reply: MessageCircle; share: Share2;
  report: Flag; block: Ban; moderation: Shield; prediction: Crosshair.

Icons never replace conventional text for destructive, authentication, or form
submission actions.
